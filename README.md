# MaxGrowth 外贸报价与跟单工作台

一个面向外贸业务员、外贸跟单、外贸 SOHO 和中小型 B2B 出海企业的本地部署效率工具。

项目目标是把外贸日常工作中高频、重复、容易出错的流程工具化，例如客户资料管理、产品资料管理、报价单、PI、订单跟进、单证生成、CBM / 装柜计算和数据备份。

> 当前版本：v0.6.1 订单看板强化版 / 邀请码内测版
> 数据模式：本地浏览器保存，不上传服务器
> 适用场景：轻量报价、跟单、订单状态管理、单证辅助生成

## 这个工具解决什么问题？

很多外贸企业的日常工作并不是没有流程，而是流程分散在不同工具里：

* 客户资料放在 Excel、微信、邮箱里
* 产品价格和包装参数到处查
* 报价单和 PI 反复复制粘贴
* 订单状态靠聊天记录记忆
* Commercial Invoice、Packing List、Shipping Mark 重复整理
* CBM、毛重、净重、装柜数量反复手算
* 报价后、PI 后、发货前容易忘记跟进

MaxGrowth 外贸报价与跟单工作台希望把这些重复、低效、容易出错的动作，整理成一个轻量工具流程。

## v0.6.1 版本核心变化

### 1. 首页升级为订单看板

v0.6.1 不再只展示客户数、产品数、报价单数等基础数量，而是将首页改成更贴近跟单场景的订单经营看板。

首页重点展示：

* 订单总金额
* 已收款金额
* 待收款金额
* 生产中订单
* 待发货订单
* 单证待处理
* 风险订单
* 今日待跟进

这样跟单人员打开首页后，可以优先看到当前订单推进情况，而不是单纯看到工具数据数量。

### 2. 订单管理成为主线

当前版本的产品逻辑调整为：

```text
客户 / 产品 = 基础资料
报价单 / PI = 订单前置流程
订单 = 跟单主线
收款 / 生产 / 发货 / 单证 = 订单推进节点
```

订单管理中增加了更多真实跟单字段：

* 订单金额
* 已收款金额
* 待收款金额
* 付款状态
* 生产状态
* 质检状态
* 包装状态
* 发货状态
* 单证状态
* 交期
* 下一步动作
* 风险状态

### 3. 增加订单作战卡

每个订单可以查看更完整的订单详情，用于集中查看：

* 订单基础信息
* 收款信息
* 生产进度
* 发货进度
* 单证状态
* 包装与装柜数据
* 下一步动作
* 自定义备注

### 4. 单证状态并入订单

单证不再只是一个孤立工具，而是与订单状态关联。

订单中可以跟进：

* Commercial Invoice
* Packing List
* Shipping Mark
* Bill of Lading
* Certificate of Origin
* 其他自定义单证或证书

单证中心仍然保留，用于从订单数据快速生成常用单证内容。

### 5. 增加自定义字段

不同行业的跟单流程不完全一样，因此 v0.6.1 增加了简单自定义字段，用于适配更多行业场景。

例如：

* 机械设备：调试状态、验厂状态、木箱包装
* 化工材料：MSDS、COA、危险品资料
* 医疗器械：CE、FDA、ISO、注册资料
* 建材产品：项目编号、颜色、尺寸、批次
* 定制产品：打样、图纸确认、开模状态

### 6. 左侧导航支持滚动

为适配不同浏览器比例、笔记本屏幕和缩放比例，v0.6.1 优化了左侧导航栏。

左侧菜单区域支持独立滚动，避免底部「数据管理」「公司设置」在小屏幕下无法点击。

## 数据安全说明

当前版本是静态网页工具，不连接数据库，不上传客户数据。

所有数据默认保存在当前浏览器本地。请定期使用「数据管理」中的导出备份功能。

如果出现以下情况，数据不会自动同步：

* 清理浏览器缓存
* 更换浏览器
* 更换电脑
* 使用无痕模式

因此建议重要数据定期导出备份。
