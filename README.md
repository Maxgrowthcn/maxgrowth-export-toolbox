# MaxGrowth 外贸报价与跟单工作台

一个面向外贸业务员、跟单人员和中小型 B2B 出海企业的本地部署效率工具。

该工具由 MaxGrowth 制作，用于减少外贸日常工作中的重复录入、重复计算、重复制单和重复跟进，让业务员把更多时间放在客户开发、报价转化和订单推进上。

## 核心功能

### 客户管理

* 记录客户公司、联系人、国家、邮箱、WhatsApp 等信息
* 支持客户备注
* 可从客户直接创建报价单

### 产品管理

* 记录产品名称、型号、规格、默认价格、成本价、MOQ、HS Code
* 支持包装数据维护：每箱数量、箱规、净重、毛重
* 后续可用于自动计算 CBM、Packing List 和订单单证

### 报价单

* 创建外贸报价单
* 支持多个产品行
* 支持成本、单价、折扣、利润率计算
* 支持复制报价单
* 支持从报价单转为 PI

### 形式发票 PI

* 创建 Proforma Invoice
* 支持客户、产品、金额、付款方式、贸易条款、银行信息等内容
* 支持 PI 转订单

### 订单管理

* 从 PI 一键转为订单
* 记录定金状态、生产状态、质检状态、包装状态、发货状态、单证状态
* 跟踪交期和下一步动作

### 单证中心

支持从订单生成：

* Commercial Invoice
* Packing List
* Shipping Mark
* 出货文件 Checklist

### CBM / 装柜计算

* 计算单箱 CBM
* 汇总总 CBM、总毛重、总净重
* 支持 20GP / 40GP / 40HQ 装柜粗估

### 跟进任务

* 记录报价跟进、PI 付款跟进、订单状态跟进
* 首页显示今日任务、逾期任务和待处理提醒

### 数据管理

* 数据保存在当前浏览器本地
* 支持导出完整 JSON 备份
* 支持导入备份
* 支持导出客户 CSV
* 支持导出产品 CSV

## 数据安全说明

本工具当前为静态网页版本，不连接数据库，不上传客户数据。

所有数据默认保存在当前浏览器本地。请定期使用「数据管理」中的导出备份功能。

如果清理浏览器缓存、更换浏览器或更换电脑，原数据不会自动同步。

## 当前限制

当前版本适合轻量使用和内测体验，暂不支持：

* 多账号登录
* 团队协作
* 云端同步
* 后端数据库
* 真正安全的邀请码权限
* AI 自动生成开发信
* 联网客户背调

这些能力适合后续升级为 SaaS 版本。
